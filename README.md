# Projeto Flask

Projeto desenvolvido em Python utilizando o framework Flask.

## Tecnologias

- Python 3.12+
- Flask
- uv

## Instalação

Clone o repositório:

```bash
git clone https://github.com/DaviMarquesPires/Flask.git
cd Flask
```

Instale as dependências:

```bash
uv sync
```

## Executar

```bash
uv run projeto-flask
```
